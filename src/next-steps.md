# Where to go next

This book covers the common path through Nostr Dev Kit. Continue with the appropriate reference for APIs and protocol
details that are outside that path.

## Rust API reference

- [`nostr` API documentation](https://docs.rs/nostr)
- [`nostr-sdk` API documentation](https://docs.rs/nostr-sdk)
- [Rust source and examples](https://github.com/nostrdevkit/nostr)

## Native packages

The package pages provide releases and platform metadata:

- [Python package on PyPI](https://pypi.org/project/nostr-sdk)
- JavaScript packages: [Node.js](https://www.npmjs.com/package/@nostrdevkit/nostr-sdk-node),
  [Web](https://www.npmjs.com/package/@nostrdevkit/nostr-sdk-web), and
  [React Native](https://www.npmjs.com/package/@nostrdevkit/nostr-sdk-react-native)
- Kotlin artifacts: [Android](https://central.sonatype.com/artifact/org.nostrdevkit/nostr-sdk),
  [JVM](https://central.sonatype.com/artifact/org.nostrdevkit/nostr-sdk-jvm), and
  [Kotlin Multiplatform](https://central.sonatype.com/artifact/org.nostrdevkit/nostr-sdk-kmp)
- [Swift package](https://github.com/nostrdevkit/nostr-sdk-swift)
- [C# package on NuGet](https://www.nuget.org/packages/Nostr.Sdk)
- [Binding source, examples, and platform support](https://github.com/nostrdevkit/nostr-sdk-ffi)

## Protocol reference

Use the [NIP repository](https://github.com/nostr-protocol/nips) for wire semantics and interoperability requirements.
The API shows how to construct a value; the relevant NIP defines how other clients and relays interpret it.
